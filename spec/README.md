# Devbox Agents: specification

One app (VS Code) to start, follow and find back AI coding agents (Claude Code, Codex) on a remote development machine (the "dev box"). The agents run on the server and keep running when the laptop is closed.

This folder describes what the extension must do and why. The [README](../README.md) in the repository root describes how to use it.

| File | Contents |
|---|---|
| [01-environment.md](01-environment.md) | The setup the extension is designed for |
| [02-requirements.md](02-requirements.md) | What users need, numbered R1–R17 |
| [03-constraints.md](03-constraints.md) | Hard constraints and findings that shaped the design |
| [04-architecture.md](04-architecture.md) | How the extension meets the requirements |
| [05-decisions.md](05-decisions.md) | Decisions taken on earlier open questions, and what is still open |

Requirements are referred to as R1–R17 throughout the other files.
